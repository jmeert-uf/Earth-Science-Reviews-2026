This repository contains data, text, figures and juypter notebooks used in Meert et al. (2026) Earth Science Reviews Paper which can be found https://www.sciencedirect.com/science/article/pii/S0012825226002114 .

Note: The Supplementary Tables (Site level data) will be updated regularly as new data are added.   Please email me jmeert@ufl.edu if you have recently published Proterozoic paleomagnetic data from India

The kmz geochron and paleomagnetic site files will also be updated regularly

Geochron Analysis files include some re-calculated dat

Geochron Excel file contains detrital zircon data from the Vindhyan Basin and will be updated regularly with newly published data

All other files are legacy text, figures and table files from the final publication

Any errors contact me at jmeert@ufl.edu
